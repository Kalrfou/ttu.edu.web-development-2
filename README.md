# Web Development 2  
**Tafila Technical University (TTU)**

## Course Overview
This repository contains the official course materials for **Web Development 2** at **Tafila Technical University**.  
The course focuses on advanced web application development, covering both front-end and back-end concepts, modern frameworks, and best practices in web engineering.

---

## Course Objectives
By the end of this course, students will be able to:
- Develop dynamic and data-driven web applications
- Apply MVC and layered architectures
- Implement server-side logic
- Integrate databases with web applications
- Handle user input, validation, and sessions
- Use Git and GitHub for version control
- Apply responsive design and modern UI styling
- Follow clean code and software engineering principles

---

## Technologies and Tools
- HTML5, CSS3, JavaScript
- Bootstrap or modern CSS frameworks
- Server-side development
- MVC architecture
- Relational databases (SQL)
- Git and GitHub
